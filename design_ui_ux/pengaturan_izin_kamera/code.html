Panduan Masalah Izin & Perangkat
Pastikan webcam tersambung erat ke port USB atau periksa pengaturan privasi sistem operasi Anda (mis. macOS System Settings > Privacy & Security > Camera). Segarkan halaman setelah mengizinkan akses.
Klik ikon gembok kecil di samping URL address bar browser Anda. Ubah setelan "Kamera" dari "Blokir" menjadi "Izinkan", kemudian muat ulang halaman ini untuk menerapkan perubahan.
Hanya satu aplikasi yang dapat mengakses modul optik dalam satu waktu. Tutup Zoom, Google Meet, FaceTime, atau tab peramban lain yang mungkin sedang aktif menggunakan kamera.
